   Автор: Sarz_656

Тут лежат мои программы на Python.
Все написаны с нуля, работают локально, ничего не отправляют в интернет.
----------------------------------------
СПИСОК ПРОГРАММ
----------------------------------------
1. cleaner — Чистильщик мусора PRO
   Что делает:
   • Чистит временные файлы, кэш браузеров, мессенджеров
   • Очищает корзину
   • Запускает встроенную очистку диска Windows (C: и D: кароче твои)
   • Ищет самые большие файлы и папки на дисках
   Файл запуска: cleaner\ЗАПУСТИТЬ СОФТ.bat
2. qrcode_gen — Генератор QR-кодов
   Что делает:
   • Создаёт QR из текста, ссылок, Wi-Fi, телефона, email
   • Сохраняет в PNG
   • Показывает предпросмотр
   Файл запуска: qrcode_gen\ЗАПУСТИТЬ QR.bat
----------------------------------------
КАК ЗАПУСКАТЬ
----------------------------------------
Открой папку нужной программы и запусти .bat файл двойным кликом.
Например: cleaner\ЗАПУСТИТЬ СОФТ.bat
----------------------------------------
ЧТО НУЖНО ДЛЯ РАБОТЫ
----------------------------------------
• Windows 10 или 11
• Python 3.10 или новее (установлен и добавлен в PATH)
• Библиотеки:
  - для cleaner: ничего дополнительно (стандартные модули)
  - для qrcode_gen: qrcode, pillow
    Установка: pip install qrcode pillow
Если что-то не запускается — сначала проверь, установлен ли Python.
----------------------------------------
БЕЗОПАСНОСТЬ
----------------------------------------
• Программы работают только локально, никуда не звонят.
• Права администратора нужны только для доступа к системным папкам.
• Все действия пишутся в лог: cleaner_log.txt и error_log.txt.
• Удаление происходит только по твоему подтверждению.
