## 📦 Что внутри

### 🧹 Cleaner PRO — Чистильщик мусора

Мощная утилита для очистки Windows от мусора.

**Что умеет:**
- Чистит временные файлы, кэш браузеров (Chrome, Edge, Firefox, Opera, Brave, Yandex)
- Чистит кэш мессенджеров (Telegram, Discord, Skype)
- Очищает корзину
- Запускает встроенную очистку диска Windows (C: и D:) автоматически
- Ищет самые большие файлы и папки на дисках
- Пишет лог очистки в `cleaner_log.txt`

**Запуск:** `cleaner\ЗАПУСТИТЬ СОФТ.bat`

---

### 📱 QR Code Generator — Генератор QR-кодов

Простой генератор QR-кодов с тёмной заставкой.

**Что умеет:**
- Создаёт QR из текста, ссылок, данных Wi-Fi, телефона, email
- Сохраняет в PNG
- Показывает предпросмотр в окне
- Поддерживает вставку через кнопку и правый клик

**Запуск:** `qrcode_gen\ЗАПУСТИТЬ QR.bat`
